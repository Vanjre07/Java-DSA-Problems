# Java DSA

This repository contains Java solutions and practice programs for data structures and algorithms.

## Topics

- Arrays
- Binary Search Trees
- Hashing
- Linked Lists
- Queues
- Stacks
- Trees
- Tries

## Running a program

Compile and run a Java file from the project directory. For example:

```bash
javac Arrays/Spiral_Matrix_Traversal_LT54.java
java -cp Arrays Spiral_Matrix_Traversal_LT54
```
