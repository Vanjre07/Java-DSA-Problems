# Java DSA Problems

A collection of **Data Structures and Algorithms (DSA) solutions implemented in Java**. This repository is a personal coding-practice workspace for learning core concepts, improving problem-solving skills, and revising commonly used algorithms.

## 📚 Topics Covered

The repository currently includes practice problems across these topics:

| Topic | What you'll practice |
|---|---|
| Arrays | Traversal, searching, sorting, and matrix problems |
| Binary Search Trees | BST operations and search-based problems |
| Hashing | Hash maps, hash sets, and frequency-based problems |
| Linked Lists | Traversal, insertion, deletion, and linked-list techniques |
| Queues | Queue operations and related problem-solving patterns |
| Stacks | Stack operations and stack-based problems |
| Trees | Tree traversals and common binary-tree problems |
| Tries | Prefix trees and string-prefix operations |

> Browse the folders in the repository to explore the Java solutions for each topic.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Vanjre07/Java-DSA-Problems.git
cd Java-DSA-Problems
```

### 2. Open a topic folder

Choose the topic you want to practice and open the corresponding `.java` file.

### 3. Compile and run a solution

Make sure the Java Development Kit (JDK) is installed. From the repository root, compile a file and run its class. For example:

```bash
javac Arrays/Spiral_Matrix_Traversal_LT54.java
java -cp Arrays Spiral_Matrix_Traversal_LT54
```

The class name used with the `java` command should match the class declared in the file.
